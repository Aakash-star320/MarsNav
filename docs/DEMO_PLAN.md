# 30-second demo plan

| Time | Visual / narration |
|---|---|
| 0–3s | Global Mars map; select supported AOI and “hydrated-mineral evidence.” |
| 3–8s | Analysis status and source cards reveal actual coverage/provenance/limits. |
| 8–13s | Local imagery/elevation/hazard/science layers and evidence-backed target. |
| 13–19s | Local assistant request; show extracted limits and real typed tool action. |
| 19–24s | 2D/DEM-derived 3D route with distance/slope/science/return/coverage metrics. |
| 24–27s | Draw obstacle; deterministic replan and changed metrics. |
| 27–30s | HUD guidance plus “prepared locally/offline” label. |

Record source/provenance screens and assumptions separately for judges. Avoid unreadable text, claims of certified safety, and any synthetic fixture presented as NASA data.
